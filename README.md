# Prompt Packs

The free prompts behind the films we post. Copy one, paste it into a coding AI that can write and run files, and build it yourself.

## 3D
| Prompt | What it builds |
|---|---|
| [Robot dog simulator](3d/robot-dog-simulator.md) | A 30-second film of a robot dog that is really simulated: it walks, trots and bounds up a step, and every graph on screen is computed live from the simulation (three.js, all generated by code). |

## How to use
1. Open a prompt and copy everything below the line.
2. Paste it into a coding AI with a terminal and a browser.
3. Let it plan, check its own stills, then render. Expect a review round or two.

The prompts are free. Running them uses your own coding AI plan and computer.
